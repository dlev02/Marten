# Mobbin refinement review

Reviewed September 11, 2026 through the authenticated Mobbin MCP. The research inspected 26 returned screen previews from 19 web apps. These are captured product screens, not live interaction tests. No competitor screenshots are bundled in Marten.

| Area                 | Observed reference                                                                                                                                                                                                   | Adopted in Marten                                                                                                                                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Authentication       | [Clay login](https://mobbin.com/screens/d2e3fb23-922d-4b6a-9d65-fd9abf5570c6) gives the form and primary action a clear hierarchy.                                                                                   | Direct sign-in/sign-up headings, no generic security slogan, and a compact sample-data demo action immediately below the form. The demo placement is our adaptation; that exact pattern was not present in the reference. |
| Empty credit history | [Wise connected accounts](https://mobbin.com/screens/629ffc1a-2986-43bf-ae93-1c4744451351) retains navigation and gives an empty page one clear next action.                                                         | A quiet gauge icon, direct explanation, primary Add your first score and secondary Import PDF in the same panel.                                                                                                          |
| Settings navigation  | [Firecrawl settings](https://mobbin.com/screens/89894be8-96d7-466e-abf0-0b0d1633b358) uses a secondary sidebar; [Acctual](https://mobbin.com/screens/1ebfe9b2-35fd-42b6-8786-d8666743c964) uses tabs for a flat set. | Retain the lighter secondary sidebar for Marten's eight sections, with horizontal navigation on mobile. Keep its position coordinated with the sticky sample-data banner.                                                 |
| Command search       | [Supabase command palette](https://mobbin.com/screens/9b4725f5-e038-4fc7-98ad-64a59f74b4d7) groups shortcuts, queries and actions with icons and an active row.                                                      | Group navigation, settings and data results, show result-type icons, keep keyboard focus in the search field and expose the active result with combobox semantics. A Raycast web screen was not verified.                 |
| Date filtering       | [PayPal activity](https://mobbin.com/screens/3476a7a1-0286-400c-9d27-3c6ce87ad842) combines presets and explicit start/end fields.                                                                                   | Add common date presets above custom fields, with the applied preset/range visible on the toolbar. Preserve the existing accessible single-date calendars.                                                                |
| Forecast controls    | [Origin forecast setup](https://mobbin.com/screens/7c5d3bcb-74d4-40e2-a021-10d524562dc2) pairs a spending slider with exact amounts.                                                                                 | Pair retirement-age, return and inflation sliders with exact numeric entry and units. The reference does not establish those financial defaults or slider bounds; Marten's engine remains the source for validation.      |

The [Origin calendar](https://mobbin.com/screens/77f87b26-6d67-4706-89eb-25493b268102) shows a larger two-month picker and layered confirmations. Marten keeps its smaller, reusable date fields instead of adding a second calendar implementation. [Linear search](https://mobbin.com/screens/a2f96ae5-202c-4747-a959-d33d7e5c0f72) informed result taxonomy, but is a full-page search rather than the palette reference.

Other fixes came from Drew's direct review: align profile-photo actions, remove score-input steppers, keep desktop sidebar controls at stable positions, and disable net-worth path interpolation while resizing. See [verification](../verification.md) for actual runtime evidence; these references alone do not establish usability or accessibility.

## September 13, 2026 · Bank connections

Reviewed Monarch's [Institutions screen](https://mobbin.com/screens/21140009-1eb3-41d7-881e-93a6fa6f3ec3): bank identity, provider/update metadata and account rows stay together, while secondary maintenance actions are subordinate to Add account. Adopted grouping and concise metadata in Marten's connected-service cards. Also reviewed its bank-connection flow with alternate-provider choices. Marten places service choice first, with Plaid product selection disclosed only when relevant; Lunch Flow's API does not provide Monarch's success ratings, so those are not reproduced. The [request-new-connection form](https://mobbin.com/screens/94b3de60-bc54-471e-9b9b-9e95bddee7e6) was reviewed but not adopted: connection coverage remains the provider's responsibility.

The [Monarch category settings screen](https://mobbin.com/screens/b9d5efb1-4299-4814-87dd-ecd0b8cf896a) was also reviewed for clear income/expense group hierarchy and editable rows. Expanded Marten’s starter groups using Drew’s requested household categories and existing illustrations; omitted an extra instructional banner.
