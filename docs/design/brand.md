# Marten identity

The current cross-product rules live in [DESIGN.md](../../DESIGN.md). This page
retains the identity decisions, asset provenance, and generation brief.

Drew requested a new name, original logo, and an accent other than orange. **Marten** replaces the temporary Folio name. The mark is a composed woodland marten with its tail curling around it. Neutral surfaces, financial charts, and the existing product organization remain the foundation.

## Assets and color

- Production mark: [public/marten-mark.png](../../public/marten-mark.png), created with the built-in image-generation tool. It has a transparent background; the application uses its alpha as a theme-colored CSS mask.
- Light accent: `#356587`; hover: `#295472`; text on accent: white.
- Dark accent: `#83b8d5`; hover: `#a2cee6`; text on accent: `#152b3b`.
- Wordmark: live DM Sans text, with the same locally bundled/system-font preference as the application.
- Existing browser-storage keys and internal `components/folio` paths keep their identifiers to preserve sessions and preferences. User-facing copy, email display name, Plaid client name, page title, favicon, and export names use Marten.

This is an original personal-project identity, not a trademark-availability opinion. The older Folio concept screenshots remain historical design references.

## Generation prompt

> Use case: logo-brand. Create one finished brand icon for Marten, a calm and beautifully simple personal finance app. A distinctive abstract pine marten in profile, with a graceful long curled tail forming an open protective circle around its body. Refined Swiss/Scandinavian identity design, bold simple filled shapes, slightly rounded geometry, distinctive little round ear and short snout, clever negative space, recognisable at 24 pixels. Animal should feel alert, composed, friendly but adult, not cartoonish. Color palette: ONLY one solid muted petrol blue #356587, with genuinely transparent background and no white rectangular canvas. Square composition, single icon centered, symbol occupies 84 percent of canvas. Vector-like crisp flat silhouette edges. No text, no typography, no coins, no dollar signs, no charts, no gradients, no shadows, no texture, no bounding tile, no mockup, no watermark. This is the actual icon asset, not a presentation sheet. Output transparent PNG.

## Category artwork

The [Marten category library](category-icons/README.md) extends the identity through rounded flat shapes and a shared petrol blue, sage, ochre, terracotta, cream, and slate palette. Everyday objects carry category meaning; the marten itself remains the product mark. Drew selected this direction from an image-generated style sheet on September 12, 2026. Production SVGs use fewer interior details so they remain recognizable in transaction rows.
